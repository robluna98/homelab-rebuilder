# homelab-rebuilder
Infrastructure-as-code for rebuilding and automating my full Proxmox LXC-based homelab. Includes provisioning containers, installing and configuring media services (Jellyfin, Sonarr, Radarr, Homarr, etc.), and setting up consistent hostname-based SSH access using Ansible.

API data provided by [GetSongBPM](https://getsongbpm.com)
